# NinjaNext Apps Privacy

Privacy policies for apps published by NinjaNext (http://ninjanexttech.com/ — info@ninjanexttech.com). This repository is served by GitHub Pages at https://ninjanext.github.io/NinjaNext-Apps-Privacy/, with one folder per app containing that app's privacy policy as a static HTML page. The landing page lists every app and links to its policy.
